# Architecture Records

Durable records in this directory:

- `FOUNDING-DISPOSITION.md` — establishes Draneka Intelligence as a peer platform domain and defines the execution-vs-domain-authority boundary.
- `DOMAIN-MAP.md` — records the peer-domain relationship and Intelligence Inbox placement.
- `CUSTODY.md` — preserves current and future repository/domain custody boundaries.
- `POST-CONSOLIDATION-EXPLORATION.md` — parks unresolved architecture questions until Core → Journal consolidation is complete.
- `STATUS.md` — current gate/status summary.

These records are architecture authority only. They do not authorize production JI, datastore, provider, repository, deployment, or database migrations.
