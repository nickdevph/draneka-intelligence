# Architecture Custody

This repository is the durable home for future Draneka Intelligence architecture and implementation work.

Current custody rules:

- `draneka-intelligence` owns future Draneka Intelligence domain architecture.
- `aquaticfinder-intelligence-work` retains its existing operational/evidence role until a separately authorized migration decision is made.
- Journal and Breeder remain authoritative for their own domain records.
- No existing production JI custody is transferred solely because this repository exists.
- Further architecture work is parked behind the Core → Journal consolidation gate.

Any future change to these custody boundaries requires an explicit, reviewable disposition rather than implicit drift.
