# Exploration Gate

Draneka Intelligence architecture exploration is deliberately paused while Core → Journal consolidation is active.

## Gate closed

Do not begin implementation planning for Intelligence datastore consolidation, repository convergence, cross-domain Inbox rollout, or JI runtime migration while the Core → Journal target topology is still changing.

## Gate opens when

Either:

1. Core → Journal consolidation reaches a qualified terminal state suitable for downstream architecture work; or
2. the Founder explicitly reopens Draneka Intelligence exploration earlier.

## First action after gate opens

Perform a fresh, independent architecture review using the then-current production topology and current JI implementation as evidence. Do not treat the September 2026 exploratory ideas as implementation instructions.
